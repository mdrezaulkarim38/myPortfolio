## 🚀 Run Locally (For Developers)

```bash
# 1. Clone
git clone https://github.com/mdrezaulkarim38/myPortfolio.git
cd myPortfolio/portfolio

# 2. Install
npm install

# 3. Run dev server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build
npm run preview

# 6. Deploy (Firebase — maintainers only)
# npm install -g firebase-tools
# firebase login
# firebase deploy
```

**Requirements:** Node.js 20+, npm 10+
